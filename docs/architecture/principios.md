Velocity Engineering Principles

1.
Form follows function.

2.
Architecture precedes code.

3.
One responsibility per component.

4.
Prefer redesign over patching.

5.
Tests are immutable baselines.

6.
Everything is replaceable.

7.
Every important decision is documented.

8.
Visualization is built on architecture,
never the opposite.

9.
Composition over inheritance whenever possible.

10.
Simplicity is a feature.

11.
The user or environment may err; the simulator must remain safe.

12.
Canonical definitions are immutable.

13.
Structural errors never become active.

14.
A modeled adverse outcome is a valid learning result.

15.
Platform integrity is non-negotiable.

16.
Changes are transactional and preserve
the Last Known Good state.
