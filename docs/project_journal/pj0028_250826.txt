diseñarse correctamente sin definir:

- qué construye una factory;

- qué recibe;

- qué devuelve;

- quién posee recursos;

- quién limpia;

- cómo se realiza rollback;

- cómo se administran Nodes;

- quién posee DeviceBus;

- qué conserva CompositionPlan.

Decisiones aceptadas:

✔ Runtime factory construye solamente.

✔ Factory no inicializa lifecycle.

✔ Factory no ejecuta set_ready.

✔ Factory no ejecuta start.

✔ Factory no coordina shutdown global.

✔ Factory no crea DeviceBus global.

✔ Factory no adjunta host objects.

✔ Factory no descubre dependencias.

✔ Factory no consulta service locator.

RuntimeDependencyBinding:

Campos conceptuales:

Dependency ID

Dependency Value

Ownership

Dependency Value:

Object no null

Ownership:

BORROWED

o

TRANSFERRED

BORROWED:

✔ Owner original permanece.

✔ Handle puede utilizar.

✔ Handle no libera.

✔ Factory release no libera.

TRANSFERRED:

✔ Caller conserva ownership
  antes de build.

✔ Transferencia comienza
  al invocar factory.build().

✔ Factory es custodio
  durante construcción.

✔ Handle asume ownership
  en éxito.

✔ Factory limpia en fallo.

✔ Caller no ejecuta
  segundo cleanup.
