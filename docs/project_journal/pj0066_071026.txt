Playable Vehicle Composition 1.0

Problema:

Vehicle Composition necesita actuator latency para force/torque outputs
sin modificar Propulsion, Hover, Steering o Brake RuntimeUnits, sin timers
y sin queues no acotadas.

Requisitos aprobados:

- BoundedLatencyBuffer;
- finite signed scalar values;
- monotonic capture/flush timestamps;
- fixed delay;
- explicit flush(timestamp) from coordinator;
- capacity and overflow observable;
- zero-delay equivalent to baseline in the same tick;
- no RigidBody, RuntimeUnit or SceneTree ownership.

Alternativas:

1. Añadir delay dentro de cada RuntimeUnit.

Rechazada. Duplica policy y mezcla actuation timing con command/model
responsibilities.

2. Adapter con métodos de Propulsion/Hover/Steering/Brake combinados.

Rechazada. Introduce APIs de módulos futuros y viola no amalgamation.

3. Foundation genérica basada en Callable.

Seleccionada. Wrappers actuator-specific implementarán apply_* y
delegarán a submit_scalar; este componente solo gestiona scalar timing.

Contrato:

DelayedScalarSinkAdapter(
    target_callable(value, application_timestamp) -> bool,
    bounded_latency_buffer
)

submit_scalar(value, capture_timestamp) -> bool
flush(current_timestamp) -> bool
clear()

Semántica:

- target Callable debe ser válido y aceptar dos argumentos;
- value puede ser positivo, negativo o cero, pero siempre finite;
- conceptual application timestamp = capture + configured delay;
- submit nunca llama al target directamente;
- zero-delay requiere submit + flush en el mismo tick;
- capture timestamps y flush timestamps son monotónicos no decrecientes;
- full queue rechaza newest;
- flush drena FIFO con budget máximo igual a capacity;
- false/non-boolean target result detiene flush;
- el comando rechazado se descarta;
- comandos posteriores permanecen pendientes;
- no se reintenta efecto físico de resultado desconocido;
- clear reinicia queue, timestamp epochs y counters.

Observabilidad:

- pending count;
- maximum pending entries;
- delay seconds;
- last flush accepted count;
- total applied count.
