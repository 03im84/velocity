Problema:

BrakeCommand representa normalized brake, pero falta un model puro que
convierta brake intent y signed longitudinal speed en fuerza opuesta al
movimiento sin conocer body, motion source o sink.

Decisión:

Añadir LongitudinalBrakeModel inmutable con deadzone y fuerza escalar
firmada/acotada.

Parámetros:

max_brake_force_newtons >= 0
speed_deadzone_meters_per_second >= 0

Formula:

if abs(speed) <= deadzone:
    force = 0
else:
    force = -sign(speed) * normalized_brake * max_force

Safety:

- invalid configuration fails neutral;
- normalized brake fuera de [0, 1] fails neutral;
- non-finite brake/speed fails neutral;
- exact deadzone boundary produces zero force;
- force siempre se opone al signed movement;
- output permanece dentro de [-max_force, max_force];
- zero-force model permanece neutral.

No responsabilidades:

- LongitudinalMotionSource;
- BrakeForceSink;
- BrakeCommand parsing;
- timestep/crossing prevention;
- DeviceBus;
- Hover;
- Vector3/RigidBody;
- mutable configuration.
