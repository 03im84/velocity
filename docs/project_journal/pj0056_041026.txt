PJ0056 – Propulsion Runtime Slice 1.0 Problem and Analysis

Fecha: 04/10/2026

Baseline:

3a1f7de docs(tools): record delivery rollback baseline

Target:

Playable Vertical Slice 1.0

Problema:

Velocity produce VehicleControlCommand validado, pero todavía no posee un actuator que convierta un PropulsionCommand especializado en una salida longitudinal de fuerza finita y acotada.

Restricciones:

- Input no aplica fuerza;
- Input no publica propulsion directamente;
- Propulsion no interpreta steering o brake;
- Core no depende de RigidBody3D;
- Factory construct-only;
- Simulation-only;
- dependencies explícitas;
- fuerza limitada antes del sink;
- no singleton/autoload/service locator/thread.

Alternativas:

A. Input aplica fuerza directamente.
Rechazada: viola ADR-014.

B. Propulsion consume VehicleControlCommand.
No seleccionada: mezcla routing del vehículo con actuation.

C. Vehicle Control Router + Actuator completos ahora.
Válida pero diferida: duplica el alcance y adelanta brake/steering.

D. Actuator especializado con command, modelo y sink.
Seleccionada.

Decisión aprobada por el usuario:

Aprobar Alternativa D.

Arquitectura propuesta:

PropulsionCommand
→ PropulsionRuntimeUnit
→ LongitudinalPropulsionModel
→ PropulsionForceSink

Geometría:

- resultante longitudinal escalar y firmada;
- transferencia command-to-force lineal;
- sin dispersión radial;
- sin cono de fuerza;
- sin reparto entre toberas;
- sin punto de aplicación o torque en 1.0.

propulsion_command

Tradeoff aceptado:

El Slice 1.0 no mueve todavía una nave completa. Entrega un actuator seguro y componible.
