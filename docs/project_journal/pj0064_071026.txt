Problema:

Vehicle Composition necesita representar bias, noise acotado y
quantization de distancia sin introducir RNG global, estado oculto ni
acoplamiento con PhysicsDistanceProvider, Hover o SceneTree.

Requisitos aprobados:

- max_abs_noise_meters finito y no negativo;
- quantization_step_meters finito y no negativo;
- bias_meters finito;
- output finito y no negativo;
- noise deterministic bajo source explícito;
- no RNG global;
- zero-noise mode preserva baseline;
- source seedable/sequence-driven pertenece al conditioning pipeline.

Alternativas:

1. RNG global dentro del model.

Rechazada. Introduce estado implícito, orden global y tests frágiles.

2. RandomNumberGenerator seedable poseído por DistanceNoiseModel.

Viable, pero hace stateful al model y mezcla generación con
transformación matemática.

3. Normalized sample explícito por llamada.

Seleccionada. DistanceNoiseModel permanece puro e inmutable. El futuro
ConditionedDistanceProvider poseerá NoiseSource y entregará cada sample.

Contrato:

condition_distance_meters(raw_distance_meters, normalized_noise_sample)

Pipeline:

bounded_sample = clamp(sample, -1, 1)
bounded_noise = bounded_sample * max_abs_noise_meters
conditioned = max(0, raw + bias + bounded_noise)
quantized = nearest multiple of step when step > 0

Decisiones:

- sample finito fuera de [-1, 1] se acota;
- sample no finito falla neutral a 0.0;
- raw negativo/no finito falla neutral a 0.0;
- configuración inválida falla neutral a 0.0;
- quantization se aplica después del clamp no negativo;
- resultado quantized vuelve a validarse;
- configuración 0/0/0 preserva raw distance exactamente;
- no setter ni API de source/provider/latency/physics.
