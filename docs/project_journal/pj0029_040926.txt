Problema 1:

Dashboard cuenta escenas y runs,
pero no agrega:

Checks

Check Failures

Missing Metrics

La salida actual de cada test contiene:

Checks: N

Failures: N

Pero PowerShell Runner no transforma
esos valores en un contrato estructurado.

Dashboard solo interpreta:

Total runs

Passed

Failed

Problema 2:

Las suites se configuran manualmente.

Suites existentes:

DeviceBus

DeviceCore

Providers

Profiles

Message Contracts

Debug

Categorías nuevas ausentes:

DeviceGraph

Composition

DeviceCatalog

Runtime

Los tests nuevos pueden terminar como:

Other

Problema 3:

velocity_test_dashboard.py contiene
dos definiciones de:

copy_command()

La segunda reemplaza silenciosamente
a la primera.

Dashboard 0.4.0 conservará
una sola implementación.

Problema 4:

run_godot_tests.ps1 no inicializa
explícitamente por ejecución:

engineErrorDetected

Runner 0.4.0 inicializará:

$engineErrorDetected = $false

antes de procesar output.

Decisión de métricas:

PowerShell Runner permanece
como autoridad.

Runner extraerá:

Checks

Failures

desde el summary del test.

Runner emitirá por attempt:

VELOCITY_TEST_METRICS_JSON

Formato conceptual:

{
  "version": 1,
  "scene": "res://...",
  "attempt": 1,
  "available": true,
  "checks": 24,
  "check_failures": 0
}

Métrica ausente:

{
  "version": 1,
  "scene": "res://...",
  "attempt": 1,
  "available": false,
  "checks": null,
  "check_failures": null
}

Política de métrica ausente:

✔ PASS del Runner se conserva.

✔ Dashboard no redefine PASS.

✔ Metrics se marca MISSING.

✔ Missing Metrics se agrega
  al resumen.

✔ Cero checks no se confunde
  con métrica ausente.

Check Failures:

Si el test emite:

Failures mayor que cero

y ExitCode es cero:

Runner debe devolver FAIL.

Esto aplica defensa contra
un test que reporte fallos
pero no propague ExitCode.

Repeat:

Cada attempt emite un marker.

Dashboard suma:

Checks de attempts disponibles.

Check Failures de attempts disponibles.

Missing Metrics por attempt ausente.

Pause y Resume:

✔ PASS anteriores conservan métricas.

✔ STOPPED se reinicia al reanudar.

✔ Metrics del test reiniciado se limpian.

✔ No se duplican checks anteriores.
