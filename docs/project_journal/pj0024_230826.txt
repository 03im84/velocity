Decisiones aceptadas:

✔ DeviceCatalog utilizará Draft–Compiler–Snapshot.

✔ DeviceCatalogDraft será editable.

✔ DeviceCatalog será inmutable.

✔ Catálogo vacío será válido.

✔ DeviceCatalog no tendrá ID propio.

✔ DeviceCatalog no tendrá versión propia.

✔ La identidad pertenece a DeviceProfile.

✔ La identidad exacta será:

  Profile ID
  +
  Profile Version

✔ Un mismo Profile ID podrá conservar
  varias versiones.

✔ Un duplicado exacto será
  Structural Error.

✔ No existirá overwrite silencioso.

✔ No existirá last write wins.

✔ No existirá get_latest().

✔ No existirá fallback automático.

✔ Resolución será exacta.

✔ Orden de entrada será preservado.

✔ get_profiles() devolverá copia.

✔ El índice interno utilizará:

  Profile ID
  →
  Profile Version
  →
  DeviceProfile

✔ El índice no utilizará key concatenada.

✔ DeviceCatalog satisfará
  DeviceProfileResolver.

✔ DeviceCatalog permanecerá separado
  de RuntimeFactoryRegistry.

✔ DeviceCatalog no conocerá factories.

✔ DeviceCatalog no creará Devices.

✔ DeviceCatalog no construirá Graph.

✔ DeviceCatalog no abrirá archivos.

✔ Persistencia permanecerá externa.
