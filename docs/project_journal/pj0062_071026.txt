PJ0062 – Canonical Tooling Test Runner and VTD Integration 0.6.0

Fecha: 07/10/2026

Baseline:

6be4a6a fix(tools): route local commit push retry

Problema:

La baseline Tooling dependía de recordar y ejecutar manualmente:

py -m unittest test/tools/test_velocity_submit.py test/tools/test_velocity_dashboard_web.py test/tools/test_velocity_test_dashboard_logic.py

Web VTD no exponía esta regresión y el fallback CLI no tenía launcher canónico.

Decisión:

Una sola autoridad:

tools/testing/velocity_tooling_tests.py

Dos entradas:

- Web VTD Tooling tab;
- CLI BAT/PowerShell/Python.

Módulos exactos:

- test_velocity_submit.py;
- test_velocity_dashboard_web.py;
- test_velocity_test_dashboard_logic.py.

Implementación:

- canonical unittest command shell-free;
- deterministic plan/summary;
- exit code preserved;
- ToolingTestService worker;
- live output via SSE;
- Run/Stop controls;
- process-tree termination;
- explicit pipe cleanup;
- operation exclusion with Godot/Delivery/Settings/Shutdown;
- CLI independent from Web server.

Defecto detectado durante verificación:

ResourceWarning por stdout pipe no cerrado.

Corrección:

process.stdout.close() en finally antes de finalizar worker.
